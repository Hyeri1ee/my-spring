# chapter1 AWS 시작하기

## 1.1 AWS 개요

인프라스트럭쳐(infrastructure) : 애플리케이션/서비스를 구축하고 운영하는 환경

## 1.2 클라우드

클라우드(cloud) : 네트워크를 통해 서버,스토리지,네트워크와 같은 컴퓨터 리소스를 서비스로 제공하는 비즈니스를 말함

### 1.2.1 컴퓨터 리소스로서의 클라우드

소유 : 모든 리소스를 기업 안에서 관리하는 방식 (온프레미스)
      필요 컴퓨터 리소스를 기업이 모두 구매하고 구축, 운영한다. -> 초기 큰 비용

임대 : 컴퓨터 리소스를 소유하기는 어려운만큼 임대 형태 등장. 컴퓨터 리소스를 빌려주는 기업과 계약을 맺고 
      필요한 만큼 리소스를 빌리는 형태. -> 이러한 임대 형태는 보통 1개월 단위로, '즉시 이용해야 할때' 대응이 어려움.

클라우드 : 컴퓨터 리소스를 시간/분 단위로 임대할 수 있다.

### 1.2.3 IaaS, PaaS, SaaS


클라우드라고 해도 제공하는 서비스 수준에 따라 형태가 다양.

- IaaS
  - 서버나 네트워크를 임대 형식과 마찬가지로 서비스로 제공.
  - 구축된 서버에 os, 미들웨어(mysql등)을 직접 설치해야함.
- PaaS
  - 어플을 작동시키는데 필요한 플랫폼 자체를 서비스로 제공.
- SaaS
  - 클라우드 제공자가 전용 어플까지 제공
